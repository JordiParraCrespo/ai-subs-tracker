## Why one Claude Code login is no longer the whole picture

Plenty of developers now pay for more than one AI coding plan: a personal Claude plan, a work seat, a ChatGPT plan for Codex, maybe a spare account for side projects. Each one meters usage in its own windows and resets on its own clock. The CLI shows you the login you are signed into, one at a time, so the question that matters — *which of my accounts should I be using right now?* — has no answer anywhere.

The cost of not knowing is quiet. A weekly allowance you paid for resets unused while you burn through another account's 5-hour window and hit a limit mid-task.

## What a Claude Code usage tracker should show

A useful tracker answers four questions for every account, not just the current one:

1. **What is left** in each limit window: the 5-hour session window and the weekly one.
2. **When each window resets**, so you know what expires first.
3. **Which account to use next**, taking both into account.
4. **What the usage is worth**, so you can tell whether a plan pays for itself.

## How Subtrack tracks your usage

Subtrack is a desktop app. It finds the Claude Code and Codex logins already on your computer and, for each one, asks the provider for its limit windows: Claude Code's own usage endpoint, and Codex's ChatGPT usage endpoint, falling back to the rate limits Codex writes in its session logs. It identifies itself honestly to each vendor as `subtrack-desktop`.

Tokens are counted from the CLIs' own transcripts, per model and per day, and priced at the vendors' API rates. That is how the [pricing guide](/claude-code-pricing/) can compare a plan's price with what the same usage would cost on the API.

<Callout>
  Subtrack never refreshes a provider's token. Claude Code's refresh tokens rotate, so a refresh from another app would sign the CLI out. Subtrack only reads.
</Callout>

## The account to use next

The queue ranks every account by **headroom per hour before its reset**: an account with 40% left that resets in two hours should be used before one with 70% left that resets in five days. Subtrack puts that account at the top of the list and in your menu bar.

When you decide to switch, marking an account as in use writes a small pointer file. An opt-in shell snippet makes `claude` and `codex` in your terminal follow it, and you can remove it at any time.

## Adding more accounts

**Add account** signs a new login into its own folder with the provider's own CLI (`claude auth login`, `codex login`), so a second login never signs the first one out. Use the accounts you hold under each vendor's terms: personal and work seats, or plans you pay for yourself.

## Renewals and what expired unused

Providers do not report a billing day, so you set it once per account. Subtrack then shows a calendar of renewals and, on the overview, how much paid allowance expired unused in the last month.
