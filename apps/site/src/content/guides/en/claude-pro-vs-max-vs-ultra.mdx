## The three plans side by side

| | Pro | Max | Ultra |
| --- | --- | --- | --- |
| Price | $20/month | $100/month | $200/month |
| Usage | Baseline | 5× Pro | Highest |
| 5-hour window | Yes | Yes | No |
| Weekly window | Yes | Yes | Yes |
| Formerly | — | Max 5x | Max 20x |

Prices are Anthropic's monthly prices in US dollars; the full list, including Team seats, is in [Claude Code pricing](/claude-code-pricing/).

## Pick Pro if you rarely hit a limit

Pro is enough when Claude Code is one tool among several and your sessions are short. If you hit the 5-hour limit once in a while, waiting for it is cheaper than upgrading.

## Pick Max if the 5-hour window is your ceiling

Max multiplies Pro's usage by five. It suits daily, heavy use where the session window, not the week, is what stops you.

## Pick Ultra if your sessions run long

Ultra removes the 5-hour window. Long agent runs only count against the weekly limit, which is the main reason to choose it over Max.

<Callout>
  Before you change plan, check the numbers: how often each window ran out last month, and what your usage would have cost on the API. Subtrack shows both per account, so the decision comes from your own data.
</Callout>

## Count the allowance you are not using

Upgrading is not the only lever. If you already hold more than one plan, the allowance that resets unused each week is money spent for nothing. The [usage limits guide](/claude-code-usage-limits/) explains how to order your accounts so that does not happen.
